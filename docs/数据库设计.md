## 几个要提前定的点

1. **角色用枚举还是关联表？** 毕设场景用 `sys_user.role` 单字段（ADMIN / STAFF / OWNER）就够，别上 RBAC 五张表，答辩讲不清。
2. **车主怎么登录？** 小程序用 `wx.login` 拿 code → 后端换 openid。`openid` 唯一索引。管理员/员工走账密登录。所以 `password` 允许为空。
3. **积分怎么记？** 用户表存 `points` 余额（方便查询），`points_record` 存流水（方便对账和论文里讲"积分明细"）。
4. **订单状态机**：待接单 → 服务中 → 已完成 / 已取消。状态流转写在 Service 层，别散落在 Controller。
