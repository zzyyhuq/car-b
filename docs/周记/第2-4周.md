## 二、页面与技术清单

### 1. 全局配置

| 文件 | 内容 |
|---|---|
| `app.json` | 注册 6 个页面；tabBar 四项：首页 / 服务 / 积分商城 / 我的 |

**为什么建 `mock/data.js`**：阶段 3 接后端时只改这一个文件或页面里的请求，WXML 结构不用动。数据集中也能避免每个页面各写一份，改价格只改一处。

## 三、逐页实现

### 1. 首页 `pages/index/index`

**功能**
- 顶部渐变头图：店名 + 服务标语
- 公告栏：`swiper` 竖向轮播
- 活动区：`scroll-view scroll-x` 横向滑动卡片
- 热门服务：取 `services` 前 3 条，点击进详情
- 「我的预约」入口，切到「我的」tab

**关键点**
- 公告用 `<swiper vertical autoplay circular interval="3000">`
- 横向滑动活动卡用 `scroll-view` + `white-space: nowrap` + 卡片 `display: inline-block`
- 跳详情：`wx.navigateTo`；跳 tab 页：`wx.switchTab`

### 2. 服务列表 `pages/service/list`

**功能**
- 搜索框：按名称或简介模糊匹配
- 分类栏：全部 / 洗车 / 内饰 / 漆面 / 保养
- 服务卡片：emoji、名称、标签、简介、价格、时长、「预约」按钮
- 空状态：没有匹配结果时显示提示

**实现**
```js
applyFilter() {
  const { activeCategory, keyword } = this.data
  const filtered = mock.services.filter(item => {
    const matchCategory = activeCategory === '全部' || item.category === activeCategory
    const matchKeyword = !keyword || item.name.includes(keyword) || item.brief.includes(keyword)
    return matchCategory && matchKeyword
  })
  this.setData({ filtered })
}
```

- 分类切换和搜索都调用同一个 `applyFilter`
- 「预约」按钮用 `catchtap`，避免和卡片点击冒泡冲突

### 3. 服务详情 `pages/service/detail`

**功能**
- 渐变头图显示 emoji、名称、简介
- 价格卡：价格、时长、分类、积分倍率、免费停车
- 服务内容清单
- 预约须知
- 底部固定栏：合计价格 + 「立即预约」

**实现**
- `onLoad(options)` 取 `options.id`，从 mock 里查服务
- `wx.setNavigationBarTitle` 把导航栏标题改成服务名
- 底部栏 `position: fixed` + `env(safe-area-inset-bottom)` 适配全面屏
- 预约：`wx.navigateTo('/pages/order/create?id=' + id)`

### 4. 下单 `pages/order/create`

**功能**
- 服务项目信息
- 选择车辆：单选卡片，第二辆可选
- 选择日期：`picker mode="date"`，最早今天
- 选择时段：7 个可选时段（09:00–17:00）
- 备注：`textarea`，最多 100 字
- 提交预约

**提交逻辑**
```js
const order = {
  id: Date.now(),
  orderNo: 'BM' + String(Date.now()).slice(-10),
  serviceId, serviceName, price,
  carPlate, carName,
  date, time, remark,
  status: '待接单',
  createTime: '2026-11-18 18:34'
}
const orders = wx.getStorageSync('beauty_orders') || []
orders.unshift(order)
wx.setStorageSync('beauty_orders', orders)
```

- 未选时段时 `wx.showToast` 拦截
- 用 `submitting` 标记防止重复提交
- 成功后 `wx.showModal` 提示，确认后 `wx.switchTab` 跳到「我的」
- 订单状态先写死为「待接单」，阶段 3 由后端返回真实状态

### 5. 我的 `pages/mine/index`

**功能**
- 用户卡片：头像占位、昵称、车主身份、积分
- 统计：我的订单数、车辆数、可兑商品数
- 我的车辆列表
- 我的订单列表：服务名、状态、车辆、预约时间、单号、金额
- 空状态 + 「去预约」按钮
- 菜单：积分商城、车辆管理（占位）、留言反馈（占位）

**关键点**
- 订单读取放在 `onShow` 而不是 `onLoad`：因为页面是 tab 页，从下单页 `switchTab` 回来不会重新触发 `onLoad`，只在 `onShow` 里刷新才能看到新订单。

### 6. 积分商城 `pages/points/mall`

- 只做占位页：积分余额、4 个商品卡片、兑换按钮弹确认框
- 兑换弹窗提示「阶段 4 接入接口」，保证 tabBar 完整、页面不空白

## 六、踩过的坑 / 学到的东西

| 问题 | 原因 / 解决 |
|---|---|
| 从首页跳服务列表失败 | 服务列表是 tabBar 页面，必须用 `wx.switchTab`，`navigateTo` 只能跳非 tab 页 |
| 下单后回「我的」看不到新订单 | tab 页切换只触发 `onShow`，不触发 `onLoad`；订单读取挪到 `onShow` |
| 搜索结果不刷新 | `setData` 之后才能拿到新值，筛选逻辑要放在回调里执行 |
| 底部按钮被 tabBar 挡住 | 固定底栏页面（详情、下单）单独加 `padding-bottom`，并用 `env(safe-area-inset-bottom)` |
| 外链图片加载失败 | 小程序需要配置合法域名；阶段 1 全部用 emoji 占位 |
