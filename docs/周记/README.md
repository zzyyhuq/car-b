## 记录规范（后面继续照这个写）

每个阶段/周新建一个文件，至少包含：

1. **目标与验收标准** —— 这一阶段要做到什么
2. **完成内容** —— 按功能点列，写清楚涉及的文件和实现方式
3. **关键设计决定** —— 为什么这么做，答辩时能直接用
4. **验证记录** —— 执行过的命令、测试用例、结果
5. **踩过的坑** —— 问题、原因、解决办法
6. **后续计划**
7. **可复用素材** —— 截图、代码片段、SQL 等
