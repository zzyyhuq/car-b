# 管理端（Vue 3）

管理员 / 门店员工使用的后台，目前包含登录、订单管理、服务项目管理、用户查询。

## 技术栈

| 组件 | 版本 | 说明 |
|---|---|---|
| Vue | 3.5 | 组合式 API |
| Vite | 8 | 开发服务器与打包 |
| Element Plus | 2.9 | UI 组件库 |
| Pinia | 2.3 | 登录态 |
| Vue Router | 4.5 | 路由与权限守卫 |
| Axios | 1.7 | 请求封装 |

## 启动

先保证后端运行在 `http://localhost:8081`，然后：

```bash
cd admin-web
npm install
npm run dev
```

浏览器打开 <http://localhost:5173>。

开发服务器把 `/api` 代理到 `http://localhost:8081`，不需要额外处理跨域。
如果后端临时跑在别的端口：

```bash
VITE_API_TARGET=http://localhost:8082 npm run dev
```

## 已完成页面

- **登录**：账号密码登录，token 存 localStorage，路由守卫拦截未登录
- **订单管理**
  - 按订单号 / 车牌 / 状态 / 下单日期筛选，分页
  - 详情弹窗：服务、车辆、车主、员工、预约时间、完成/取消信息
  - 接单 → 开始服务 → 完成（完成后自动发积分）
  - 取消订单（可填原因）
  - 管理员派单：员工列表来自 `GET /api/user/page?role=STAFF`
  - 服务进度：时间线展示，已接单/服务中可登记「接车/清洗/质检/交车」节点
- **服务项目**：新增、编辑、逻辑删除、上下架、分页
- **积分商品**（仅管理员）：新增、编辑、逻辑删除、上下架、分页
- **兑换核销**（管理员/员工）：兑换单分页、状态筛选、核销（待核销 → 已核销）
- **公告管理**（仅管理员）：新增、编辑、发布/下线、删除、分页筛选
- **活动管理**（仅管理员）：新增、编辑、上线/下线、删除、起止时间维护；可设置「仅公告 / 需要报名」，需报名活动可查看报名名单
- **留言管理**（仅管理员）：评价/留言分页、类型/状态/关键词筛选、回复、审核通过/隐藏
- **用户管理**（仅管理员）：关键字 / 角色 / 状态筛选，当前只读

## 构建

```bash
npm run build
```

产物在 `dist/`。正式部署时可放到 Nginx，把 `/api` 反向代理到 Spring Boot；
后端已配置 CORS，直接跨域访问也可以。
