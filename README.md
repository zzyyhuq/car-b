# 某4S店汽车美容服务软件的设计与实现

毕业设计项目。车主端微信小程序 + 管理端 Vue 后台 + 一套 Spring Boot 后端。

## 技术栈

- 后端：Java 17 + Spring Boot 3 + MyBatis-Plus + Spring Security/JWT + MySQL 8 + Redis
- 车主端：微信小程序（原生）
- 管理端：Vue 3 + Element Plus

## 目录

| 目录 | 内容 |
|---|---|
| `backend/` | Spring Boot 后端（阶段 2 开始写） |
| `miniprogram/` | 车主端小程序（阶段 1 开始写） |
| `admin-web/` | 管理员/员工后台（阶段 4 开始写） |
| `docs/` | 数据库设计、周记（索引见 `docs/周记/README.md`）、截图、论文素材 |

## 路线图（每周 6–10 小时，共约 24 周）

| 阶段 | 周次 | 目标 | 验收标准 |
|---|---|---|---|
| 0 环境 | 第 1 周 | 装工具、注册小程序、跑通官方模板 | 开发者工具里能点一个小程序 |
| 1 前端原型 | 第 2–4 周 | 车主端 5 个页面，数据全写死 | 手机预览能走完预约流程 |
| 2 后端骨架 | 第 5–8 周 | Spring Boot + MySQL + JWT 登录 | Postman 能登录、能查列表 |
| 3 打通一条线 | 第 9–12 周 | 预约下单：小程序 → 接口 → 数据库 | 真机下单，库里能查到 |
| 4 铺模块 | 第 13–20 周 | 剩余 6 个模块 + Vue 管理后台 | 三种角色都能用 |
| 5 收尾 | 第 21–24 周 | 测试、部署、论文、答辩材料 | 能演示 + 论文初稿 |

## 七大功能模块

1. 用户管理
2. 美容订单类型管理
3. 服务过程管理
4. 美容订单管理
5. 积分商品 / 积分兑换 / 兑换明细
6. 留言簿管理
7. 通知公告及活动管理

三类角色：系统管理员 / 门店员工 / 车主。

## 工作规矩（很重要，别嫌烦）

- **每次写代码前先 `git status`，写完跑通再提交。** 一周至少两次，宁可提交半成品也别攒着。
- **每周末花 15 分钟填 `docs/周记/`。** 论文"系统实现"那一章就是这些记录拼起来的，最后再回忆写不出来。
- **卡住超过 2 小时就问人**，别自己硬扛。毕设不是考验毅力的地方。
- **先跑通，再做好看。** 界面丑不影响过，功能跑不通要命。
